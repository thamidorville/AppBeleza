# Belagora API REST

API REST para gestão e agendamento de serviços de beleza com autenticação JWT e autorização por roles.

## Stack

- .NET 9 / C#
- Dapper (micro-ORM)
- PostgreSQL
- BCrypt (hash de senhas)
- JWT Bearer Authentication
- HashIds (ofuscação de IDs)

## Como rodar

```bash
cd BelezaApp.API
dotnet run
